# 18 参考资料与阅读路径

本白皮书围绕 OPC 的产品工作路径与经济机制展开。个人云、多智能体、工作树、云端发布、业务连接、应用市场与 SIGN 结算构成产品协作；总量分配、入金配置、奖励、出局与税额分配构成机制运行。读者可以结合官方入口、公开来源和本白皮书的机制细则继续阅读。

## OPC 官方入口

- [OrangePersonalCloud GitHub](https://github.com/OrangePersonalCloud)：项目公开资料与仓库入口。
- [OPC 资料库](https://library.orangepilotcrew.com)：产品与机制资料阅读入口。
- [Orange Personal Cloud Telegram](https://t.me/OrangePersonalCloud)：官方社区入口。

阅读产品时，可以沿愿景、个人云、多智能体、业务连接、工作树、发布和市场章节展开，再通过活动应用场景理解完整工作路径。阅读经济机制时，可以从 SIGN 职责进入总量分配，继续查看流动性、奖励与出局，再结合机制运行与结算细则核对账户。两条路径共同说明 OPC 的工作场景与机制安排。

## 数字与图示的读取方法

代币数量以明确枚数为准，分配比例可出现四舍五入。收益型入金算例以 USDT 价值解释比例，动态算例以 OPC 数量解释预算；两者使用不同单位，不应混算。本文图示用于展示结构、依赖、交付和资金路径，活动应用及相关反馈均为场景示意。

本白皮书的图示与正文相互补充：结构图帮助找到对象，流程图帮助理解先后和依赖，数量图帮助核对分配。资格、价格和退出条件与对应结算记录共同运行，读者可以沿图示找到路径，再通过正文理解每项动作的作用范围与记录方式。
